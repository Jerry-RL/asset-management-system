# ADR-0008: 资产管理垂直领域 Agent 与私有化 LLM 架构

- **状态**：Accepted
- **日期**：2026-08-26
- **决策者**：架构组

## 上下文

决策层与系统管理员需要基于自然语言和模板快速生成经营分析报告（PPT、HTML、文档）。系统已具备完整租控、合同、收费等领域 API 与 RBAC，但缺少：

1. 统一智能编排层，避免各模块重复对接大模型；
2. 数据隐私与国资合规约束下的模型选型；
3. 报告指标 **可溯源、可验证**，防止 LLM 幻觉进入监管材料。

## 决策

1. 新增 **`intelligence` 领域模块**，实现 **Tool-First Agent 编排**：数值与状态仅来自系统 Tool/API，LLM 负责规划、叙述与格式编排。
2. **默认私有化 LLM**（内网推理服务）；公有云模型仅作 fallback，且必须经过脱敏网关，`AGENT_REQUIRE_PRIVATE=true` 为生产默认。
3. 报告输出经 **Citation Engine + Output Validator** 校验后方可导出；完整 Prompt/Tool/模型调用写入审计表。
4. Agent **只读**业务数据；写操作仅生成用户可确认的草稿，不在 Agent 内直接提交。
5. 报告渲染与长任务使用 **异步队列**（BullMQ），HTML 同步预览、PPT/PDF 异步生成。

## 备选方案

| 方案 | 优点 | 缺点 | 结论 |
|------|------|------|------|
| A. 各报表模块独立接 LLM | 上线快 | 无法统一审计、易幻觉、重复建设 | 拒绝 |
| B. 纯 RAG 问答，无 Tool | 实现简单 | 无法保证数值准确 | 拒绝 |
| C. Tool-First Agent + 私有化 LLM | 准确、可审计、合规 | 工程量大 | **采纳** |
| D. 完全依赖外部 BI + 无 LLM | 无模型风险 | 无法满足 NL 与智能解读 | 仅作降级 |

## 后果

### 正面

- 决策报告生成效率提升，且指标可点击溯源。
- 安全、审计、RBAC 与现有体系一致。
- 模板与 Tool 可复用于后续智能定价（FR-AI-001）等 P2 能力。

### 负面

- 需 GPU/推理资源与 Agent 运维能力。
- 模板与 Tool 白名单需持续维护。

### 风险与缓解

| 风险 | 缓解 |
|------|------|
| LLM 幻觉 | Validator + 禁止未验证导出 |
| 延迟高 | 异步渲染 + 流式 SSE |
| 模型版本变更 | Model Router 版本 pinning + 回归用例 |
