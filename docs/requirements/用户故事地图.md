---

## 1. 地图结构说明

- **横向（用户活动）**：时间顺序的业务主线
- **纵向（优先级）**：自上而下 MVP → 增强 → 未来
- **角色**：资产管理员、运营、财务、审批人、租户、外勤、系统管理员

---

## 2. 用户故事地图（可视化）

```mermaid
flowchart TB

    A5 --> A6[履约维保] --> A7[续签或退租]
```

## 4. 发布切片（Release Slicing）

| 版本 | 包含故事优先级 | 目标 |
|------|----------------|------|
| R1 MVP | 全部 P0 活动 1–8 核心路径 | 可运营闭环 |
| R2 | P1 计划、催缴升级、水电、业财、SLA、合规 | 经营提效 |
| R3 | P2 电子签、无形资产、智能分析 | 智能化扩展 |

与 SRS §4.25 Wave 对齐。
