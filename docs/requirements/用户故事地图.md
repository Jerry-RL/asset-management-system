## 1. 地图结构说明

- **横向（用户活动）**：时间顺序的业务主线
- **纵向（优先级）**：自上而下 MVP → 增强 → 未来
- **角色**：资产管理员、运营、财务、审批人、租户、外勤、系统管理员、决策层

---

## 4. 发布切片（Release Slicing）

| 版本 | 包含故事优先级 | 目标 |
|------|----------------|------|
| R1 MVP | 全部 P0 活动 1–8、10–11 | 十三条闭环可验收 |
| R2 | P1 计划、催缴升级、水电公摊、业财统一对账、SLA、合规、合同状态机、任务超时、资产调拨、脱敏矩阵、资金互抵、我的合同、智能报告 | 经营提效 |
| R3 | P2 电子签、无形资产、智能分析/RAG、集团合并看板、监管报送 | 智能化扩展 |

与 SRS §4.25 Wave 对齐。Agent（W6/W7）按价值导向建议后置，先保现金流闭环（催缴/对账/迁移）。
