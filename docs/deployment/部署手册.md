## 1. 适用范围

资产经营管理系统 **后端 API、PC 管理端、数据库与中间件** 的部署与升级。小程序通过微信开发者平台发布，本文仅说明配置项。

## 2. 环境清单

| 环境 | 用途 | 域名示例 |
|------|------|----------|
| DEV | 开发 | dev-api.example.com |
| TEST | 测试 | test-api.example.com |
| STAGING | 预发/UAT | staging-api.example.com |
| PROD | 生产 | api.example.com |

## 3. 软硬件要求

| 组件 | 最低（TEST） | 推荐（PROD） |

## 5. 配置说明

### 5.1 后端 `backend/.env`

```env
NODE_ENV=production
PORT=3000
API_PREFIX=/api/v1
DATABASE_URL=postgresql://ams:***@pg-host:5432/ams
REDIS_URL=redis://redis-host:6379/0
JWT_ACCESS_SECRET=<强随机>
JWT_REFRESH_SECRET=<强随机>
OSS_ENDPOINT=
OSS_BUCKET=
WECHAT_APP_ID_TENANT=
WECHAT_APP_SECRET_TENANT=
```

完整项见 [部署与运维手册](./部署与运维手册.md) §3。

### 5.2 PC 前端 `admin-web/.env.production`

```env
VITE_API_BASE_URL=https://api.example.com/api/v1
```

### 5.3 小程序

- `config/apiBaseUrl` 指向对应环境 API
- 微信公众平台配置服务器域名白名单

### 5.4 Nginx（示例）

```nginx
server {
  listen 443 ssl;
  server_name api.example.com;

  location /api/ {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
  }

  location /health {
    proxy_pass http://127.0.0.1:3000/api/v1/health;
  }
}
```

PC 静态站点单独 `server` 或使用 CDN。

## 6. 部署步骤

### 6.1 首次部署

```bash
# 1. 数据库
createdb ams
cd backend && pnpm run migrate

# 2. 后端
pnpm install --frozen-lockfile
pnpm run build
pm2 start dist/main.js --name ams-api -i 2

# 3. 前端
cd admin-web && pnpm install && pnpm run build
rsync -av dist/ /var/www/ams-admin/

# 4. 验证
curl https://api.example.com/api/v1/health
```

### 6.2 Docker Compose（开发/测试）

```bash
cd docker
docker compose up -d postgres redis minio
cd ../backend && pnpm run migrate && pnpm run start:prod
```

### 6.3 版本升级

1. 备份数据库（见应急预案）
2. 拉取新版本代码 / 镜像
3. `pnpm run migrate`（Flyway）
4. 滚动重启 API：`pm2 reload ams-api`
5. 部署前端静态资源
6. 执行冒烟：登录、资产列表、合同查询、健康检查

### 6.4 回滚

- 应用：回滚至上一 Git tag / 镜像
- 数据库：仅回滚应用；schema 变更需提前准备 `U*` 脚本或从备份恢复（见应急预案）
