### 1. 系统组件

| 组件 | 版本 | 说明 |
|------|------|------|
| Node.js | 20 LTS | API 服务 |
| PostgreSQL | 15+ | 主库 |
| Redis | 7+ | 缓存/幂等/锁 |
| MinIO / OSS | - | 附件 |
| Nginx | 1.24+ | 反向代理、静态资源 |

```

├── backend/          # Express API

├── tenant-mp/        # 用户端小程序
├── worker-mp/        # 工作端小程序
├── docker/           # Docker Compose
└── docs/
```


```env
VITE_API_BASE_URL=https://api.example.com/api/v1
```

### 4. Docker Compose 启动（开发/测试）

```bash
cd docker
cp .env.example .env
docker compose up -d postgres redis minio
cd ../backend
pnpm install
pnpm run migrate    # flyway migrate
pnpm run dev
```

生产建议使用 `docker compose -f docker-compose.prod.yml up -d`（含 API + Nginx）。

### 5. 构建与启动命令

**后端**

```bash
cd backend
pnpm install --frozen-lockfile
pnpm run build
pnpm run start:prod
```

**PC 前端**

```bash
cd admin-web
pnpm install
pnpm run build
# 静态文件部署至 Nginx root 或 OSS CDN
```

**小程序**：使用微信开发者工具上传，`app.js` 中配置 `apiBaseUrl`。

### 6. 健康检查

| 接口 | 说明 |
|------|------|
| `GET /api/v1/health` | 返回 `status`, `db`, `redis`, `version` |
| `GET /api/v1/health/ready` | K8s readiness（DB 连通） |
| `GET /api/v1/health/live` | K8s liveness |

Nginx 探活示例：

```nginx
location /health {
  proxy_pass http://127.0.0.1:3000/api/v1/health;
}
```

### 7. 数据库初始化

```bash
cd backend
pnpm run migrate        # 执行 Flyway V*.sql
pnpm run seed:dev       # 可选：开发种子数据
```

## 第二部分：运维手册

### 1. 日志

| 类型 | 路径/方式 | 级别 |
|------|-----------|------|
| 应用日志 | `logs/app-%DATE%.log` 或 stdout（容器） | info |
| 访问日志 | Nginx `access.log` | - |
| 审计日志 | DB `operation_log` | 不可删改 |
| 错误 | 含 `traceId`，对接 Sentry 可选 | error |

日志格式（JSON）：

```json
{"time":"...","level":"info","traceId":"abc","msg":"...","userId":1}
```

### 2. 监控与告警

| 指标 | 阈值建议 | 告警 |
|------|----------|------|
| API P95 延迟 | > 2s 持续 5min | 警告 |
| 5xx 比例 | > 1% | 严重 |
| PG 连接数 | > 80% max | 警告 |
| Redis 内存 | > 85% | 警告 |
| 磁盘 | > 85% | 严重 |
| 健康检查失败 | 连续 3 次 | 严重 |

推荐：Prometheus + Grafana，或云监控。

### 3. 备份策略

| 对象 | 频率 | 保留 | 恢复演练 |
|------|------|------|----------|
| PostgreSQL 全量 | 每日 02:00 | 30 天 | 季度 |
| PostgreSQL WAL | 实时 | 7 天 | - |
| Redis | RDB 每日 | 7 天 | - |
| OSS 附件 | 跨区域复制 | 按合规 | 年度 |

恢复命令示例：

```bash
pg_restore -d ams_restore backup.dump
```

### 4. 常见故障 FAQ

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 登录 401 | Token 过期/时钟漂移 | 清缓存重新登录；检查服务器时间 |
| 支付成功未入账 | 回调验签失败 | 查 `callback` 日志；微信商户平台补单 |
| 账单金额不对 | 计划未重算 | 检查合同版本与 payment_plan |
| 租控状态错误 | 手工改库 | 禁止手改；走退租/合同流程修复 |
| 上传失败 | OSS 凭证过期 | 更新 `.env` 密钥 |
| 慢查询 | 缺索引 | 查 PG slow log；对照数据库设计文档索引 |
| Flyway 失败 | 脚本冲突 | 禁止跳版本；修复脚本后重新 migrate |

### 5. 发布与回滚

**发布**

1. 备份数据库
2. 执行 `flyway migrate`
3. 滚动更新 API 实例
4. 部署前端静态资源
5. 执行冒烟用例（TC-AUTH-001, TC-CON-001, TC-BIL-001）

**回滚**

1. 回滚应用镜像/代码到上一 tag
2. 若迁移可逆：执行配套 `U*` 脚本（须提前编写）
3. 数据库迁移不可逆时：**禁止**回滚 schema，只回滚代码并 hotfix

### 6. 安全运维

- 生产密钥仅存环境变量/密钥管理服务，不入库
- 定期轮换 JWT secret、OSS 密钥
- 仅堡垒机访问 DB；生产禁止 `root` 直连
