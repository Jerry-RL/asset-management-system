## 2. 项目概述

### 2.1 建设背景

面向地方国资国企、城投集团等主体，对经营性资产进行集中统一管理，覆盖资产登记、招租租赁、合同签约、收费财务、巡检维保、处置退出等全生命周期业务，实现资产运营线上化、数据化管理。

### 2.2 建设目标

系统建设应实现：

1. **资产盘清**：构建全域动态资产台账，账实相符、数据可追溯。
2. **经营提效**：招租—签约—收付—监管全流程数字化，提升出租率与收缴率。
3. **合规安全**：权证、合同、审批、日志留痕，满足国资监管要求。
4. **监管有效**：驾驶舱、地图、预警、报表支撑决策与风险管控。

建设模式概括为：**资产一本账、布局一幅图、管理一张屏、资债全局览**。

### 2.3 系统组成

采用 **PC 管理后台 + 小程序用户端 + 小程序工作端** 三端一体化架构：

| 端 | 使用对象 | 主要场景 |
|----|----------|----------|
| PC 管理后台 | 资产管理人员、财务、审批人、系统管理员 | 台账维护、租控运营、合同审批、收费对账、报表分析、系统配置 |
| 小程序用户端 | 承租方租户 | 身份绑定、线上缴费、报修报事、招租报名、消息通知 |
| 小程序工作端 | 一线运维、外勤人员 | 任务处理、现场巡检、收费办理、催租张贴、合同审批 |

### 2.4 用户角色

| 角色 | 说明 | 主要使用端 |
|------|------|------------|
| 系统管理员 | 组织架构、角色权限、系统参数、日志审计 | PC |
| 运营管理员 | 招租、租控、合同、租户、平台内容配置 | PC |
| 资产管理员 | 项目/台账、权证、地图、处置 | PC |
| 财务人员 | 收费大厅、发票、欠费催缴、报表 | PC |
| 维修管理员 | 报修受理、维修公司、巡查、工单闭环 | PC |
| 审批人员 | 合同审批、招租审批、流程节点处理 | PC / 工作端 |
| 办事员/业务员 | 日常业务录入与查询 | PC |
| 承租方租户 | 缴费、报修、招租、查看消息 | 用户端 |
| 外勤运维人员 | 巡检、维修、收费、催租、审批 | 工作端 |

角色与菜单、数据权限通过 RBAC 配置，支持按公司、部门、项目维度授权。

## 3. 系统总体描述

### 3.1 业务全景

资产全生命周期闭环：

```
资产入库/登记 → 权证建档 → 招租发布 → 租赁签约 → 履约缴费 → 巡检维修 → 资产处置 → 资产退出
```

各阶段数据在「资产档案」中贯通，形成动态台账。

### 3.2 功能架构（PC 管理后台）

依据设计稿菜单与功能清单，PC 端功能划分为以下域：

| 一级域 | 二级模块 |
|--------|----------|
| 首页与工作台 | 首页、工作台设置 |
| 经营分析 | 经营看板、数据报表、资产地图 |
| 风险管控 | 预警管理（提醒、配置、记录） |
| 资产台账 | 项目管理、资产台账、资产详情 |
| 资债权证 | 权证总览、接收信息、产权信息、价值信息、评估申请、权属流转、资产调拨、抵押列表、经营信息 |
| 资产招租 | 招租管理、招租审批 |
| 资产运营 | 资产租控、资产租赁、资产自用、资产处置 |
| 合同管理 | 合同管理、合同模板、合同审批、退租退费、流程设置 |
| 收费与发票 | 收费大厅、保证金大厅、缴费订单、历史欠费、其他缴费、收款记录、发票管理、发票税率、发票抬头、发票核销 |
| 履约催缴 | 欠费管理、催缴管理、催缴模板 |
| 巡检维修 | 资产报修、维修公司、巡查管理 |
| 任务中心 | 任务管理 |
| 固定资产 | 固资看板、资产清单、资产管理、资产盘点、资产报表 |
| 基础设置 | 位置设置、分类设置、折旧设置、审批设置 |
| 组织架构 | 组织架构、公司管理、公司类型、人员维护 |
| 运营管理 | 用户管理、租户管理、平台管理、信息管理 |
| 系统配置 | 经营资产配置、三方配置、工作端管理、页面布局 |
| 系统管理 | 系统菜单管理、角色权限、角色账号、登录日志、系统日志 |

### 3.3 约束与假设

1. 系统按 **同时在线 200 人** 规模设计，满足项目管理人员同步操作。
2. 业务操作响应流畅的前提为：甲方办公网络带宽充足、无防火墙限流、无运营商故障；网络类问题不归属系统故障。
3. 部署可采用云服务器或私有化部署，支持 Linux / Windows 常见操作系统。
4. 设计稿中部分 Tab（如预算管理）在功能清单中未展开，本期以功能清单及已提供设计稿为准；预算类能力可作为后续迭代预留。

## 4. 功能需求

### 4.1 通用能力

#### 4.1.1 登录与认证

**需求编号**：FR-COM-001

| 项目 | 要求 |
|------|------|
| 描述 | PC 端提供账号密码登录，含图形验证码 |
| 输入 | 账号、密码、验证码 |
| 处理 | 校验凭证；失败提示原因；支持会话保持与安全退出 |
| 输出 | 登录成功后进入首页/工作台 |
| 设计参考 | 登录页/登录页面.png |

#### 4.1.2 全局导航与多 Tab 工作台

**需求编号**：FR-COM-002

- 左侧树形菜单 + 顶部 Tab 多页签，支持模块间快速切换。
- 支持「全局资产/全局局产」等数据范围切换（按授权公司过滤）。
- 首页提供应用中心入口，按 **经营性资产、固定资产、数智管理、无形资产** 等分类聚合功能（设计稿首页）。

#### 4.1.3 列表页通用能力

**需求编号**：FR-COM-003

各业务列表页应统一支持：

- 条件筛选、关键字搜索、重置、刷新
- 分页（每页条数可选）
- 新增、编辑、详情、删除（按权限）
- 导入、导出、下载模板（按模块需要）
- 批量操作（如批量催缴、组合租赁等）

#### 4.1.4 操作日志

**需求编号**：FR-COM-004

- 记录用户登录、关键业务操作（增删改、审批、收费、作废等）。
- 支持按时间、用户、模块查询（系统日志、登录日志）。
