# 测试用例

> 用例 ID 格式：`TC-{模块}-{序号}`  
> 标记：`SMOKE` 冒烟 | `REGRESSION` 回归 | `P0/P1/P2` 对应需求优先级

| ID | 标题 | 优先级 | 标记 | 步骤 | 预期 |
|----|------|--------|------|------|------|
| TC-AUTH-001 | PC 正确登录 | P0 | SMOKE | 输入正确账号密码验证码 | 返回 token，进入首页 |
| TC-AUTH-002 | 验证码错误 | P0 | REGRESSION | 错误验证码登录 | code=40000 |
