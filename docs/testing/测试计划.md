# 测试计划

| 版本 | V1.0 |
|------|------|
| 日期 | 2026-08-26 |
| 依据 | SRS V2.2 |

## 1. 测试范围

### 1.1 在范围内

- PC 管理后台全模块功能
- 小程序用户端、工作端核心流程
- API 契约（OpenAPI）
- 十三条业务闭环（SRS §10.1、§4.27）
- P0 / P1 / P2 全量需求（按 Wave 分轮次执行）

### 1.2 不在范围内

- 第三方 SLA（微信、电子签平台自身故障）
- 客户本地网络、防火墙策略

## 2. 测试环境

| 环境 | 用途 | 数据 |
|------|------|------|
| DEV | 开发自测 | 造数脚本 |
| TEST | 功能/集成测试 | 脱敏副本 + 造数 |
| STAGING | 回归/UAT | 生产量级抽样 |
| PROD | 冒烟 only | 真实 |

**最低配置（TEST）**：与生产同版本 PG、Redis；对象存储 MinIO；微信/支付沙箱。

## 3. 测试策略

| 类型 | 比例目标 | 工具 |
|------|----------|------|
| 单元测试 | 核心领域逻辑 ≥70% 覆盖 | Jest |
| API 契约测试 | 核心路径 100% | OpenAPI + Dredd/Schemathesis |
| 集成测试 | 主流程全覆盖 | Jest + Supertest |
| E2E | 冒烟 + 核心闭环 | Playwright（PC）/ 小程序自动化 |
| 性能 | 200 并发场景 | k6 |
| 安全 | OWASP Top10 基线 | 扫描 + 手工 |

### 3.1 冒烟测试（每次部署）

- 登录 / Token 刷新
- 资产列表查询
- 创建合同 → 审批 → 生成账单
- 模拟收款
- 健康检查 `/health`

### 3.2 回归测试

- 发版前执行 **核心用例集**（见 [测试用例.md](./测试用例.md) 标记 `REGRESSION`）
- 全量 P0 用例在 W1 完成后纳入回归集

## 4. 入口/出口标准

| 阶段 | 入口 | 出口 |
|------|------|------|
| 功能测试 | 特性开发完成、DEV 部署 | 无 P0/P1 缺陷 open |
| 集成测试 | 模块联调完成 | 十三条闭环用例（TC-LOOP-001~013）通过 |
| UAT | STAGING 就绪 | 业务方签字 |
| 上线 | UAT 通过 | 冒烟通过、回滚方案就绪 |

## 5. 缺陷等级

| 级别 | 定义 | 处理 |
|------|------|------|
| P0 | 主流程不可用、数据丢失、安全漏洞 | 阻断发布 |
| P1 | 功能错误无 workaround | 发布前修复 |
| P2 | 有 workaround 或 UI 问题 | 可带缺陷发布 |
| P3 | 建议优化 | 排期 |

## 6. 资源与排期（参考）
