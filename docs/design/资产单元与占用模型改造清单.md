## 3. 验收 SQL

```sql
-- INV-1：单元面积不得超过资产面积（期望仅 area_missing / no_unit 可解释）
SELECT * FROM v_asset_unit_budget WHERE check_result <> 'ok';

-- A1 不变量：占用面积恒等于单元面积
SELECT count(*) FROM asset_occupancy o JOIN asset_unit u ON u.id = o.asset_unit_id
 WHERE u.area <> o.area;

-- INV-2：每个资产至少一个有效单元
SELECT * FROM v_asset_without_unit;

-- 非终态合同必须已挂单元
SELECT * FROM v_contract_without_unit;

-- 派生一致性（切换读路径前必须为空）
SELECT * FROM v_asset_lease_status_reconcile;

-- 存量面积差异（仅供人工决定是否拆单元，不阻塞；视图由 V41 §2.4 创建）
SELECT * FROM v_legacy_area_mismatch;

-- 预留态（ADR-0020 决策 E）：reserving 应只存在于审批中的单据
SELECT o.subject_type, o.subject_id, count(*) AS reserved_units
  FROM asset_occupancy o
 WHERE o.biz_status = 'reserving' AND o.date_to IS NULL
 GROUP BY o.subject_type, o.subject_id;

-- 派生租控状态不得被 reserving 污染（评审 P0-6）
SELECT * FROM v_asset_lease_status_derived d
 WHERE EXISTS (SELECT 1 FROM asset_occupancy o
                WHERE o.asset_id = d.asset_id
                  AND o.biz_status = 'reserving'
                  AND CURRENT_DATE <@ daterange(o.date_from, o.date_to, '[)'))
   AND d.derived_status <> 'vacant';

-- 组合租赁占用收口完整性（评审 P0-5）：已终止合同不应残留未收口占用
SELECT c.id, c.contract_no, count(*) AS open_occupancies
  FROM contract c
  JOIN asset_occupancy o ON o.subject_type = 'contract' AND o.subject_id = c.id
 WHERE c.status = 'terminated' AND o.date_to IS NULL
 GROUP BY c.id, c.contract_no;
```

## 4. 发布顺序与注意事项

**五步走，每步可独立上线：**

0. **P0′ 语义修补（ADR-0020 决策 E/F）**：`V42__occupancy_reservation.sql` **已交付**（派生视图排除 `reserving` + `reserved_area` + `v_occupancy_reserving_orphan`），配套 `OccupancyBizStatus.RESERVING`、`findOpenBySubject` 的 `LIMIT 1` 已删除。**仍未完成的是业务链路接入**：合同/占用/自用/处置的「提交审批 → `reserve`、通过 → `activateBySubject`、驳回 → `cancelReservation`」属 §2.2 双写期改造（触点 28）。`domain_event_outbox`（决策 F）与 `contract_line`（决策 C）见后续 `V43+`。
   ⚠️ 提醒：只上预留态不上视图过滤，会造成「审批中即显示在租」的回归（评审 P0-6）；只改视图不改释放逻辑，组合租赁占用仍永久不收口（评审 P0-5）——两者本次已同批交付。
1. **P0 扩展（已完成）**：`V39~V41` + 新服务。应用写入路径**不切换**，跑 1~2 个迭代观察 §3 的差异清单。
2. **P1 双写**：§2.2 / §2.3 改造，同时保留旧 `transition` 调用；一致性作业每日比对。
3. **P2 切读**：报表 / 看板 / 统计切到 `v_asset_lease_status_derived`；`pageAssets` 切按单元统计。
4. **P3 收敛**：`V43+` 加 `CHECK (status IN ('voided','terminated','expired') OR asset_unit_id IS NOT NULL)`、删除 `asset.partial_lease_status`、`asset.lease_area` 改为派生列。

**注意事项：**

- **`ApplicationRunner` 顺序陷阱**：`DemoDataSeeder` / `DemoDataConsistencyEnricher` / `DemoProjectImageSeeder` 在 Flyway **之后**运行，其创建的资产不经过 V39 回填。必须调 `AssetUnitService.ensureUnitForAsset`，否则 `v_asset_without_unit` 会持续非空。
- **`contract.asset_id` 不可删**：全库 60+ 处引用，且 RBAC 数据范围、看板、报表均依赖。保留为冗余投影 + 一致性校验，不做全链路 JOIN 改造。
- **`lease_bundle_item` 与 `asset_unit` 的分工**：前者是 bundle 的**分配明细**（保 `area_ratio` / `rent_amount`），后者是资产的**可租标的身**身份（保 `area` / `unit_status`），两者靠 `asset_unit_id` 关联，不互为真源。
- **审批中需预留面积**：`approving` 状态的合同必须计入 `LeaseAreaGroups.AREA_HOLDING`，否则并发签约会超租；撤销时释放。
- **回填优先级是确定性的**：`contract > self_use > occupation > disposal`，重叠行被守卫跳过（实测 A10 冲突只保留 `self_use`）。被跳过的数据需人工核对，不由迁移自动裁决。
- **`area = 0` 表示面积待补**：占位单元不参与面积统计，由 `v_asset_unit_budget.area_missing` 报出。

## 5. 实测结论

在 `postgres:16-alpine` 上用合成数据跑完整迁移链（V1→V41 + 14 个覆盖各分支的资产样例）：

| 校验项 | 期望 | 实测 |
|---|---|---|
| `contract.asset_unit_id` 回填覆盖率 | 100% | `contracts_without_unit = 0` |
| 每个资产至少一个单元 | 100% | `assets_without_unit = 0`，14 资产 → 17 单元 |
| 占用回填条数 | 11 | 11（contract 6 active + 1 vacating、self_use 2、occupation 1、disposal 1） |
| A1 不变量（占用面积 == 单元面积） | 0 违例 | `a1_violations = 0 / 11` |
| 派生态识别「部分出租」 | 仅 T-A3 | 仅 `T-A3: leased → partial_leased, ratio 30.00` |
| `EXCLUDE` 拒绝重叠占用 | 违反 `ex_occupancy_unit_no_overlap` | 实测报错 `conflicting key value violates exclusion constraint` |
| `EXCLUDE` 允许不重叠区间 | 成功 | `INSERT 0 1` |
| 非排他占用（`exclusive=false`）允许重叠 | 成功 | `INSERT 0 1` |
| 冲突数据裁决 | 只保留优先级最高一条 | A10 仅 `self_use` 被回填 |
| 退租中 | `biz_status='vacating'` | 符合 |
| 无法关联的招租（整租资产） | 被诊断视图暴露 | `listings_without_unit = 1`（T-A13） |
| 存量面积差异保留 | 可查 | `v_legacy_area_mismatch`：occupation_order#1 存 400 / 单元 600 |

**一个有价值的副产物**：迁移一次性暴露出 1 处真实数据缺陷——`T-A3` 存量标记为 `leased`，但实际只出租 300/1000（30%），正确状态应为 `partial_leased`。这类「状态与实际占用不符」的存量问题，旧模型无法检出（因为它只有资产级单状态位）。
