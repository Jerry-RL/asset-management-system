## 1. 选型原则

1. **后端 Java 企业栈**：Spring Boot 3 + PostgreSQL（[ADR-0016](../adr/0016-java-spring-boot-backend.md)）。
2. **前端 React + 小程序**：PC 管理端与微信双端独立交付。
3. **契约优先**：OpenAPI 为 API 单一事实来源（ADR-0005）。
4. **Schema 单一来源**：Flyway 管理 DDL（ADR-0006、[ADR-0017](../adr/0017-mybatis-plus-flyway.md)）。
5. **先单体后拆分**：模块化单体 Spring Boot（ADR-0002）。
6. **可观测默认可用**：traceId、Actuator、Micrometer、结构化日志。
7. **安全默认开启**：Spring Security、JWT、RBAC、审计、私有化 LLM（ADR-0008）；数据分类分级与字段加密（ADR-0015、SRS §5.8）。

后端语言历史对比见 [后端技术栈横向对比.md](./后端技术栈横向对比.md)。

## 3. 明确不选 / 暂缓

| 技术 | 原因 |
|------|------|
| Node.js / Express 后端 | 已切换 Java（ADR-0016） |
| Knex / BullMQ | Superseded by MyBatis-Plus / JobRunr |
| 首期微服务 | 200 在线规模，运维成本高（ADR-0002） |
| JPA 主导 Schema | 与 Flyway 双源易漂移 |
| Camunda/Activiti | 一期轻量审批引擎覆盖（ADR-0009） |
| MongoDB 业务库 | 监管数据强一致，PostgreSQL 足够 |
| 公有云 LLM 默认 | 国资数据隐私，私有化优先（ADR-0008） |
| Kafka | 规模不足；ApplicationEvent + JobRunr 足够 |

## 4. 工程结构（混合 Monorepo）

见 DSD §3.4、[ADR-0012](../adr/0012-pnpm-monorepo-structure.md)。

```
asset-management-system/
├── backend/                 # Java Maven Spring Boot
├── frontend/                # 前端 Monorepo（pnpm workspaces）
│   ├── admin-web/           # React（pnpm）
│   ├── miniprogram-tenant/
│   ├── miniprogram-worker/
│   └── packages/
│       └── shared/
├── docs/
├── docker/
└── deploy/k8s/
```

- **后端**：`cd backend && mvn verify`
- **前端**：`cd frontend && pnpm install`（文档工具 + admin-web + 小程序）

## 5. 非功能选型映射

| NFR | 技术方案 |
|-----|----------|
| 200 在线 | Nginx 负载 + 2× API（8080）；HikariCP；Redis 缓存 |
| P95 < 2s | 分页、索引、MyBatis 避免 N+1；报表只读副本 |
| 99.5% 可用 | 多实例、Actuator 健康检查、DB 主从 |
| 审计 | `operation_log` + MyBatis 拦截器 / AOP |
| Agent 隐私 | 私有化 LLM、脱敏网关、Tool 白名单 |

## 6. 数据安全选型

| 能力 | 选型 | 说明 |
|------|------|------|
| 传输 | TLS 1.2+ / HSTS | Nginx 终止 HTTPS |
| 字段加密 | JCE AES-256-GCM | `DATA_ENCRYPTION_KEY`；TypeHandler 或 Service |
| 密码 | BCrypt（Spring Security） | cost factor 12 |
| 密钥托管 | 环境变量 / 云 KMS | 禁止入库 |
| 脱敏 | 响应 DTO AOP / `@JsonSerialize` | 按 RBAC 掩码 |
| 对象存储 | OSS/MinIO 私有 + SSE | 预签名 URL |
| 备份 | pg_dump 加密 + 异地 | RPO ≤24h |
| 依赖扫描 | OWASP Dependency-Check / Maven | CI 阻断 critical |
| 日志脱敏 | Logback 替换规则 | 禁止 L4 明文 |

详见 [数据安全设计说明书.md](./数据安全设计说明书.md)、[ADR-0015](../adr/0015-data-classification-and-encryption.md)。
