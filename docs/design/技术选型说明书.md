## 1. 选型原则

1. **与团队栈一致**：Node.js + React + PostgreSQL（用户规则）。
2. **契约优先**：OpenAPI 为 API 单一事实来源（ADR-0005）。
3. **Schema 单一来源**：Flyway 管理 DDL，应用层不反向生成库表（ADR-0006）。
4. **先单体后拆分**：模块化单体，边界清晰（ADR-0002）。
5. **可观测默认可用**：traceId、结构化日志、健康检查、业务指标。
6. **安全默认开启**：JWT、RBAC、HTTPS、审计、私有化 LLM（ADR-0008）。

## 3. 明确不选 / 暂缓

| 技术 | 原因 |
|------|------|
| 首期微服务 | 200 在线规模，运维成本高（ADR-0002） |
| Prisma 主导 Schema | 与 Flyway 双源易漂移；Knex 只读查询（ADR-0010） |
| Camunda/Activiti | 一期审批场景可用轻量引擎覆盖（ADR-0009） |
| MongoDB 业务库 | 监管数据强一致，PostgreSQL 足够 |
| 公有云 LLM 默认 | 国资数据隐私，私有化优先（ADR-0008） |
| Kafka | 规模不足；in-process 事件 + BullMQ 足够 |

## 4. 工程结构（Monorepo）

见 DSD §3.4、[ADR-0012](../adr/0012-pnpm-monorepo-structure.md)。

```
asset-management-system/
├── backend/                 # Express API
├── admin-web/               # PC React
├── miniprogram-tenant/      # 用户端小程序
├── miniprogram-worker/      # 工作端小程序
├── packages/
│   ├── api-types/           # OpenAPI 生成 TS 类型
│   └── shared/              # 共享常量、枚举（租控状态等）
├── docs/
├── docker/
└── deploy/k8s/
```

包管理：**pnpm workspaces** + Node 20。

## 5. 非功能选型映射

| NFR | 技术方案 |
|-----|----------|
| 200 在线 | Nginx 负载 + 2× API；PG 连接池；Redis 缓存热点 |
| P95 < 2s | 分页、索引、避免 N+1；报表走只读副本/物化视图 |
| 99.5% 可用 | 多实例、健康检查、DB 主从、应急预案 |
| 审计 | `operation_log` + 领域关键表 `created_by/updated_by` |
| Agent 隐私 | 私有化 LLM、脱敏网关、Tool 白名单 |
