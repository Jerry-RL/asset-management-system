| 版本 | V1.0 |
|------|------|

> **定位**：国资国企资产管理系统涉及租户个人信息、合同金额、权证资料、监管报表，**数据安全为最高优先级非功能需求之一**。本文档为 NFR-DSEC-* 的技术落地说明。

---

## 1. 合规与原则

| 法规/标准 | 适用要点 |
|-----------|----------|
| 《网络安全法》 | 等级保护、关键信息基础设施防护 |
| 《数据安全法》 | 数据分类分级、重要数据保护 |
| 《个人信息保护法》 | 租户/员工个人信息最小必要、告知同意 |
| 国资监管要求 | 经营数据、合同、处置事项长期留痕、可追溯 |

**设计原则**：最小权限、默认拒绝、加密优先、不出域、可审计、可恢复。

---

## 2. 数据分类分级

| 级别 | 代号 | 示例 | 存储/传输要求 |
|------|------|------|---------------|
| 公开 | L1 | 招租公告标题、脱敏统计 | HTTPS |
| 内部 | L2 | 资产台账汇总、经营看板 | HTTPS + RBAC |
| 敏感 | L3 | 合同全文、收款明细、权证扫描件 | 加密存储 + 严格 RBAC + 审计 |
| 高敏 | L4 | 身份证号、银行卡、密码、JWT 密钥 | 字段加密/哈希 + 脱敏展示 + 禁止导出明文 |

**字段标注**：Repository 层维护 `DataClassification` 元数据；API 响应经 `DataMaskingInterceptor` 按角色脱敏。

### 2.1 高敏字段清单（最低）

| 域 | 字段 | 措施 |
|----|------|------|
| 用户 | password | bcrypt 单向哈希，不可逆 |
| 用户/租户 | id_no、phone | AES-256-GCM 列加密 + 展示掩码 |
| 支付 | 银行卡号 | 不存储完整卡号；仅存后四位 |
| 密钥 | JWT、OSS、API Key | 环境变量/密钥管理服务，禁止入库、禁止日志 |
| Agent | Prompt 含 PII | 脱敏后存储；L4 禁止外发 LLM |

## 3. 加密与密钥

### 3.1 传输加密

- 生产 **全站 HTTPS**（TLS 1.2+，推荐 1.3）
- 内部服务间（API→PG/Redis/OSS）：私有网络或 TLS
- 小程序/PC 禁止明文 HTTP 访问生产 API

### 3.2 存储加密

| 对象 | 方案 |
|------|------|
| PostgreSQL | 云盘加密或 TDE；L4 字段应用层 AES-256-GCM（`DATA_ENCRYPTION_KEY`） |
| Redis | 启用 AUTH；生产启用 TLS；不存 L3/L4 明文 |
| OSS | 服务端 SSE-S3 或 KMS；私有桶 |
| 备份 | 加密备份文件；与生产密钥分离保管 |
| 日志 | 禁止写入 L4 明文；phone/id_no 自动掩码 |

### 3.3 密钥管理

```
DATA_ENCRYPTION_KEY   # 字段加密主密钥，KMS 或 HSM 托管
JWT_ACCESS_SECRET     # 独立轮换
JWT_REFRESH_SECRET
OSS_ACCESS_KEY        # 最小权限 RAM 子账号
```

- 轮换周期：JWT ≥ 90 天；加密主密钥 ≥ 1 年（含重加密计划）
- 开发/测试 **禁止** 使用生产密钥；样本数据须脱敏

## 4. 访问控制

### 4.1 身份与会话

- JWT Access 2h + Refresh 7d；Refresh 轮换 + 黑名单（Redis `auth:token:blacklist:{jti}`）
- 小程序：code2session + 绑定租户身份；敏感操作二次验证（可选短信）
- 闲置 30min 前端登出；并发会话可配置限制

### 4.2 授权

- RBAC：菜单 + 按钮 + **数据范围**（company/project）
- SQL 强制注入 `dataScope` 条件，禁止拼接用户输入
- 导出/批量下载：独立权限 `export:sensitive`；L3 以上记录 `export_audit`

### 4.3 特权与 break-glass

- 超管 `super_admin` 须双因素或双人审批（可配置）
- 临时提权：限时授权 + 全量审计
- 生产 DB 仅堡垒机 + 只读账号；写操作走应用层

## 5. 数据生命周期

| 阶段 | 要求 |
|------|------|
| 采集 | 最小必要；租户隐私政策告知（FR-OP-002） |
| 使用 | 按权限；Agent/报表不得越权聚合 |
| 存储 | 境内存储；重要数据不出境 |
| 共享 | 第三方 API 最小字段；签协议；脱敏 |
| 导出 | 水印（用户+时间+公司）；L4 默认禁止 |
| 归档 | 合同/收款/权证 ≥ 法规要求年限（默认永久在线+冷归档） |
| 销毁 | 仅匿名化测试数据可物理删；生产监管数据 **禁止物理删除**，仅逻辑归档 |

## 6. 日志与审计

| 类型 | 内容 | 保留 |
|------|------|------|
| `login_log` | 登录 IP、结果、客户端 | ≥ 1 年 |
| `operation_log` | 增删改、导出、审批 | ≥ 3 年 |
| `export_audit` | 导出人、范围、文件哈希 | ≥ 3 年 |
| `security_event` | 越权尝试、暴力破解、异常下载 | ≥ 3 年 |

日志防篡改：append-only 或同步至独立日志服务；生产日志访问受控。

## 7. 应用安全（与数据相关）

| 威胁 | 对策 |
|------|------|
| SQL 注入 | MyBatis 参数绑定 `#{}`；禁止 `${}` 拼接用户输入 |
| 越权访问 | RBAC + 数据范围 + 接口级校验 |
| 批量爬取 | 分页上限、rate-limit、导出审批 |
| 敏感信息泄露到日志 | pino redact 路径配置 |
| 前端泄露 | 响应脱敏；禁止 localStorage 存 Token（httpOnly Cookie 或内存） |
| 文件直链泄露 | OSS 签名 URL 15min；Referer 校验可选 |
| 供应链 | Maven OWASP Dependency-Check；CI 阻断 critical |

---

## 8. 备份、恢复与销毁

- 备份加密；恢复演练每季度（见应急预案）
- RPO ≤ 24h，RTO ≤ 4h（核心库）
- 灾备数据与生产 **同等安全级别**
- 介质销毁：云厂商合规删除；本地磁盘物理销毁流程

## 10. 验收检查项

- [ ] 生产全 HTTPS；HSTS 启用
- [ ] L4 字段加密存储；API 默认掩码展示
- [ ] 越权访问返回 403 且记 `security_event`
- [ ] 导出含水印与 `export_audit`
- [ ] 日志无密码/证件/完整手机号
- [ ] 备份加密且恢复演练记录
- [ ] Agent/LLM 生产不出域；脱敏网关生效
- [ ] 依赖扫描无 unresolved critical
