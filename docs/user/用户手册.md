# 资产经营管理系统 — 用户手册

面向 **承租方租户（小程序用户端）** 与 **内部运营/物业人员（PC / 工作端）** 的操作指引。技术人员可将本节提供给客户培训使用。

---

## 1. 系统简介

资产经营管理系统用于国有资产/经营性房产的 **在线招租、签约缴费、报修维保、台账监管**。包含：

- **PC 管理后台**：管理人员使用浏览器访问
- **用户端小程序**：租户使用微信搜索或扫码进入
- **工作端小程序**：外勤人员现场办公

---

## 2. PC 管理后台

### 2.1 登录

1. 打开系统地址（由管理员提供）
2. 输入 **账号、密码、验证码**
3. 点击「登录」

忘记密码请联系系统管理员重置。

### 2.2 首页与应用中心

- **应用中心**：按「经营性资产、固定资产、数智管理」分类进入功能
- **待办任务**：合同审批、收费、维修等待办
- **经营看板**：资产总量、出租率、收缴率等

### 2.3 资产台账

**路径**：资产管理 → 资产台账

| 操作 | 说明 |
|------|------|
| 查询 | 按来源、权属、关键字筛选 |
| 新增 | 填写项目、面积、权属等必填项 |
| 导入 | 下载模板 → 填写 → 导入 |
| 详情 | 查看一物一档：合同、缴费、维修等 |
| 二维码 | 下载张贴，供扫码查资产 |

### 2.4 招租与租赁

1. **资产租控** 查看空置/在租分布
2. **招租管理** 发布招租信息（租金或面议）
3. **公开招租**（若启用）：发公告 → 审核报名 → 中标后「添加租赁」
4. **添加租赁** 填写租户、租期、租金、保证金 → 提交审批
5. 审批通过后系统自动生成 **缴费计划**

### 2.5 收费大厅

**路径**：收费大厅

- 查看本月应收/实收、收缴率
- 对单条合同点击 **租金收取** 登记线下收款
- **其他收费**：物业费、水电等
- **费用减免 / 租金预交**：需按权限与审批规则操作

### 2.6 合同与退租

- **合同管理**：查看履约率、即将到期合同
- **续签**：到期前办理续签
- **退租**：发起退租 → 工作端清场验收 → **退租结算** → 退保证金

### 2.7 报修与巡检

- **资产报修**：受理租户报修，派工维修公司
- **巡查管理**：制定计划，现场录入隐患

### 2.8 常见问题（PC）

| 问题 | 处理 |
|------|------|
| 登录验证码看不清 | 点击验证码图片刷新 |
| 合同审批后无账单 | 联系财务确认审批是否完成；查看缴费计划 |
| 无法修改资产状态 | 租控由合同/退租驱动，不可手工改状态 |
| 导出失败 | 缩小筛选范围或联系管理员 |

## 3. 用户端小程序（租户）

### 3.1 首次使用

1. 微信打开小程序
2. 授权登录
3. **身份绑定**：实名认证，绑定名下签约资产

### 3.2 主页功能

| 入口 | 功能 |
|------|------|
| 资产缴费 | 查看账单，微信支付 |
| 报事报修 | 选资产，描述问题，上传照片 |
| 资产招租 | 浏览招租，在线报名 |
| 身份绑定 | 管理绑定资产 |

### 3.3 缴费步骤

1. 进入「资产缴费」
2. 勾选待缴账单
3. 确认金额 → 微信支付
4. 支付成功后可申请 **电子发票**（个人中心）

### 3.4 报修步骤

1. 报事报修 → 选择资产
2. 填写说明，上传照片
3. 提交后在报修记录中查看进度

### 3.5 常见问题（用户端）

| 问题 | 处理 |
|------|------|
| 找不到账单 | 确认身份已绑定正确资产 |
| 支付失败 | 稍后重试；勿重复支付，联系物业核对 |
| 报修无响应 | 查看进度；紧急电话见招租 Banner |

## 4. 工作端小程序（外勤）

### 4.1 主要功能

| 功能 | 场景 |
|------|------|
| 任务中心 | 处理待办：审批、催缴、清场等 |
| 资产查询 | 扫码或搜索资产信息 |
| 资产收费 | 现场登记收款 |
| 资产巡检 | 打卡、录隐患、上传照片 |
| 资产维修 | 接单、更新进度、完工验收 |
| 资产催租 | 张贴催缴单并拍照上传 |
| 合同审批 | 移动端审批 |

### 4.2 清场验收（退租）

1. 任务中心打开清场任务
2. 录入水电气表读数
3. 拍摄现场照片
4. 提交验收 → 财务在 PC 完成结算
